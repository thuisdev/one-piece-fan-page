# One Piece Tribute Page

A fan tribute webpage dedicated to the One Piece anime/manga series, featuring characters, lore, and legendary moments.

## Features

- Animated wave effect on the hero title
- Smooth scroll navigation
- Character cards with hover reveal facts
- Scroll-triggered fade-in animations for plot and scenes sections
- Fixed Straw Hat Pirates logo
- Responsive design for mobile screens
- Custom Pirata One font

## Tech Stack

- HTML
- CSS (animations, transitions, IntersectionObserver)
- Vanilla JavaScript

## How to Run

Open `index.html` in your browser — no installation needed.
